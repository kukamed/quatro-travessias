# Transitolândia · Quatro travessias

Apresentação dos quatro jogos de totem da área externa de *Transitolândia* (DER-DF / Convergint): da concepção à arte, aos jogos e às partidas completas, em 20 slides.

Abra `index.html` ou a página publicada. Navegue com as setas do teclado; C = capítulos; F = tela cheia. No celular em pé, os slides viram uma coluna que se rola com o dedo.
